# Plannr

Plannr is a tiny project planner: create a project, add tasks and share it with your team in seconds.

This is the gif-studio example app. From this folder:

```bash
npx gif-studio init
npx gif-studio scan
npx gif-studio app start
npx gif-studio explore
```
